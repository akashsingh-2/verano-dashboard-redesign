The Assignment Challenge

Redesign with Precision

Assignment brief: Create a dashboard where executives answer three critical questions in under two minutes. Everything leadership needs is there—but nothing has been prioritized, no visual language is coherent, and some charts actively mislead.

Information Hierarchy

Decide What Leads

Ground rule: Decide what leads, what supports, what gets cut—in priority order. Executives don't want to explore data; they want to be told what matters. V2 solves this through a three-tier visual system.

Chart Selection

Chart Types as Editorial

Several existing charts are poorly chosen for their questions. V2 replaces them with appropriate types (line for trend, bar for comparison, horizontal bar for regions) that serve the data honestly.

Visual Coherence

Consistent Design Language

The original uses arbitrary visual language. V2 applies a deliberate, consistent palette—semantic colors (positive/caution/critical), professional typography, disciplined spacing that communicates enterprise polish.

Viewport Constraint

One Screen, No Scrolling

Ground rule: 1440×900, no scrolling. This isn't about fitting data—it's about editorial decision-making. V2 proves you can deliver complete insight within this constraint through thoughtful hierarchy.

System Thinking (v3)

Scalable Foundation

Beyond v2's assignment solution, v3 demonstrates how this dashboard becomes a system: reusable components, design tokens, responsive breakpoints that scale to multiple dashboards and products.

Accessibility (Both)

Enterprise Inclusive Design

WCAG AA+ contrast, semantic HTML, ARIA labels, keyboard navigation—not as afterthought, but integral to the design. Both v2 and v3 meet accessibility standards as a foundation, not a feature.

Strategic Design Approach

Compliance + System Thinking

v2 meets every ground rule with professional excellence. v3 demonstrates the design system foundation beneath it.

Two-Track Strategy

Version 2.0 (Official Submission): Begins with the assignment requirements—real data, professional hierarchy, accessible design, exact viewport constraint. No scrolling, no storytelling, just clean decision-making for executives in a 45-minute meeting.

Version 3.0 (Enhancement): Builds on v2's foundation with a full Notion-inspired design system—sophisticated tokens, premium interactions, responsive breakpoints, micro-animations—demonstrating how this dashboard becomes the foundation for platform-wide analytics design.

The core principle underlies both: Lead the eye, not the data. Implement a three-tier hierarchy where Primary insights (30%) command attention, Secondary analysis (50%) supports exploration, and Tertiary details (20%) remain accessible but unobtrusive.

Technical Execution

How It's Built

Premium design realized through thoughtful technical implementation

Component Architecture

Each component (status cards, charts, table) is designed as a reusable pattern within the system.

  • Status Cards: Semantic layout with icon, label, value, delta
  • Filter Controls: Interactive chip pattern with reset functionality
  • Interactive Charts: Line, bar (grouped & horizontal) using Chart.js
  • Data Table: Semantic HTML with sortable regions and color-coded values

Responsive Strategy

Progressive enhancement from mobile to desktop without compromising experience.

  • Mobile (default): Single column, optimized spacing, hidden navigation
  • Tablet (768px): Two-column grids, expanded whitespace
  • Desktop (1080px+): Three-column grids, full feature set
  • Fluid typography scales with viewport smoothly

Design Tokens

CSS custom properties define every design decision for consistency and scalability.

  • 9 color tokens (canvas, surface, primary, semantic colors)
  • 5 text styles plus eyebrow and caption variants
  • 7 spacing levels (xs–3xl) on 8px base unit
  • 5 border radius sizes for consistent rounding

Interaction & Motion

Subtle, purposeful animations that enhance without overwhelming.

  • Transitions: 0.2–0.3s ease for smooth, snappy feel
  • Hover states: 2px translateY lift with shadow enhancement
  • Focus states: 2px outline with offset for accessibility
  • Prefers-reduced-motion: All transitions disabled when requested
